A chess engine in under 4 KB of Python. 0x88 board, alpha-beta search with
principal-variation search, null-move pruning, late-move reductions,
capture/promotion/check-evasion quiescence, a transposition table, killer
moves, and piece-square tables. It plays the make.fun tiny-chess-01 gauntlet
through the environment protocol (`MAKEFUN_ENV_URL`).

## Run it

```sh
python3 main.py
```
